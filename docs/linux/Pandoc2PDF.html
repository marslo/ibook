  2. 页眉: 居中, 显示内容从参数获取

ASSISTANT:

为了实现带有自定义页眉页脚的Markdown转PDF，以下是分步解决方案：

步骤1：准备CSS文件

创建两个CSS文件（保留原有代码高亮样式并添加页眉页脚）：

  1. github.css（保持原样，用于代码高亮）
  2. custom.css（新增页面布局）：
CSS
/* custom.css */
@page {
    size: A4;
    margin-top: 3cm;
    margin-bottom: 3cm;

    @top-center {
        content: var(--title); /* 从元数据获取标题 */
        font-family: DejaVu Sans, sans-serif;
        font-size: 11pt;
    }

    @bottom-right {
        content: "第" counter(page) "页/共" counter(pages) "页 · " var(--author); /* 自动页码+作者 */
        font-family: DejaVu Sans, sans-serif;
        font-size: 9pt;
        color: #666;
    }
}

body {
    font-family: DejaVu Sans, sans-serif; /* 确保中文字体 */
    padding: 0 1cm; /* 正文左右留白 */
}

步骤2：生成动态Header

通过shell脚本动态注入CSS变量（兼容元数据参数）：

BASH
#!/bin/bash

# 定义元数据
TITLE="文档标题"
AUTHOR="作者名称"
DATE="2025-03-13"

# 生成动态CSS变量
cat << EOF > header.html
<style>
:root {
    --title: "$TITLE";
    --author: "$AUTHOR";
}
</style>
EOF

步骤3：执行转换命令

使用WeasyPrint引擎的完整Pandoc命令：

BASH
pandoc -f gfm -t html5 \
--embed-resources --standalone \
--metadata title="$TITLE" \
--metadata author="$AUTHOR" \
--metadata date="$DATE" \
--toc \
--css github.css \
--css custom.css \
-H header.html \
input.md -o output.pdf \
--pdf-engine=weasyprint

验证要点说明

  1. 字体兼容性：

    • 添加DejaVu Sans字体声明确保中文显示
    • 如需其他字体，需在系统安装对应字体文件

  2. 页码逻辑验证：

    • counter(page)：当前页码
    • counter(pages)：总页数
    • WeasyPrint官方确认支持这两个计数器

  3. 布局安全区：

    • 通过margin-top/margin-bottom确保内容不重叠
    • 正文区添加padding作为二次保护

  4. 多CSS文件优先级：

    • 后引用的CSS（custom.css）会覆盖先引用的样式
    • 重要样式使用!important标签（如无需覆盖则免）

常见问题排查

Q：页眉页脚不显示？
A：检查顺序：

  1. 确认--css custom.css参数存在
  2. 查看生成HTML源码是否包含:root变量
  3. 尝试在命令行添加--verbose查看编译日志

Q：中文显示乱码？
A：解决方案：

  1. 在CSS中添加中文字体声明
  2. 安装系统中文字体包
  3. 或改用wkhtmltopdf引擎（需额外配置）

最终效果：在保持代码高亮的前提下，实现居中标题页眉和包含动态页码的右对齐页脚。
