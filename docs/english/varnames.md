## copy

| VARIABLE                          | DESCRIPTION                          |
| --------------------------------- | ------------------------------------ |
| `copy`                            | 复制，常指文件/数据的复制            |
| `sync`                            | 同步，保持两端数据一致               |
| `transfer`                        | 传输                                 |
| `move`                            | 移动，会删除源文件                   |
| `migrate`                         | 迁移，常指整体搬迁                   |
| `replicate`                       | 复刻/复制副本                        |

| `upload` / `download`             | 上传 / 下载                          |
| `deploy`                          | 部署，把文件发布到目标环境           |
| `import` / `export`               | 导入 / 导出                          |
| `backup`                          | 备份                                 |
| `dump`                            | 转储，把内容整批倒出去               |

| `distribute`                      | 分发到多个目标                       |
| `fetch`                           | 抓取到本地                           |

## trim

| VARIABLE                | DESCRIPTION                                     |
| ----------------------- | ----------------------------------------------- |
| `trim`                  | 修剪，去掉多余部分，常用于字符串/数组/文件      |
| `strip`                 | 去掉不需要的前后缀/空白，常用于字符串/文件名    |
| `prune`                 | 修剪，去掉不需要的分支/条目，常用于依赖、目录树 |
| `shrink`                | 缩小体积                                        |
| `reduce`                | 减小                                            |
| `slim` / `slim down`    | 瘦身                                            |
| `shave` / `shave off`   | 削掉一点                                        |
| `pare` / `pare down`    | 削减到精简                                      |
| `cut` / `cut down`      | 砍掉                                            |
| `clean` / `cleanup`     | 清理无用内容                                    |
| `purge`                 | 清除，彻底删掉某类内容                          |
| `compact`               | 压紧/紧凑化，去掉冗余空间                       |
| `minify`                | 最小化，常指代码/资源去空白注释                 |
| `declutter`             | 清除杂乱                                        |
| `thin` / `think out`    | 变薄/稀释                                       |

| `filter` / `filter out` | 过滤掉                                          |
| `omit`                  | 省略                                            |
| `extract`               | 提取所需部分，反向思路：只留要的                |
|                         |                                                 |
| `compress`              | 压缩                                            |
| `deflate`               | 收缩，zip 的压缩算法名                          |
| `pack` / `repack`       | 打包 / 重新打包                                 |
| `optimize`              | 优化，综合减体积                                |
